# adamleishman.com.au

A lightweight one-page personal site for Adam Leishman.

## Hosting

The site is designed for GitHub Pages with the custom domain `adamleishman.com.au`.

## Files

- `index.html` — site content and metadata
- `styles.css` — responsive presentation
- `assets/` — portrait and favicon
- `CNAME` — GitHub Pages custom domain

No build process or framework is required.
